# ⚙️ Digital Systems Design (DSD) Lab – Verilog HDL

This repository contains Verilog HDL codes for core lab experiments and exam-focused designs from the **Digital Systems Design** course at the **University of Rajshahi, CSE Department**.

> 🎯 Language: Verilog HDL  
> 💻 Tool Used: ModelSim  
> 📚 Purpose: Learn & simulate digital systems using HDL

---

## 📁 Files & Modules

| File Name         | Description |
|------------------|-------------|
| `BCDtoEX3.v`      | BCD to Excess-3 Code Converter |
| `EX3toBCD.v`      | Excess-3 to BCD Code Converter |
| `JK.v`            | JK Flip-Flop Module |
| `MOD_10_Syn.v`    | Synchronous MOD-10 Counter |
| `MOD_10_asyn.v`   | Asynchronous MOD-10 Counter (ripple counter) |
| `UP_DOWN.v`       | Up/Down Counter |
| `halfAdder.v`     | Half Adder Circuit |
| `syn.v`           | General synchronous logic (📌 last exam question) |

## ▶️ How to Simulate in ModelSim

1. **Open ModelSim.**

2. **Create a New Project**:
   - Go to **File → New → Project**.
   - Set a project name and directory.

3. **Add Source Files**:
   - Right-click on the project → **Add Existing File** → Select your `.v` files.

4. **Compile the Code**:
   - Click **Compile → Compile All**.

5. **Create a Testbench** *(optional but recommended)*:
   - Write a separate testbench `.v` file for simulation inputs.

6. **Run Simulation**:
   - Go to **Simulate → Start Simulation**.
   - Select the module and run simulation.
   - Use the **Waveform Viewer** to observe signal transitions.
